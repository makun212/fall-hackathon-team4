ロール（3つ）

豊豊太郎の葛藤を重く見る読者
  • 愛情と出世への思いの両方を見る
  • 決断の難しさと心の弱さを区別する
  • 現状を冷静に見つめている
編集済み
エエリスとの約束を重んじる読者

  • エリスを狂気に追いやった責任を豊太郎自身に厳しく問う
編集済み

  • 断ることや相談する余地を探る
