## 実装後の実施手順

1. #16担当と、入力・結果の受け渡し形式および歴史教材を扱えるか確認する。
2. 各ケースの本文・範囲を固定し、実際に使った本文と取得日を記録する。ダミー本文を本物として扱わない。
3. 実装済みの候補生成から各題材の出力を取得する。モデル名・実行日時・設定・失敗も記録する。
4. 候補数が最大6件か、名前・説明・特徴が既存画面で扱えるかを確認する。
5. ケースごとのreview_pointsで、人が視点の偏り、根拠、事実と解釈の区別を確認する。
6. 問題のある出力と改善案をセットで記録する。自動的に内容の正しさを合格と判定しない。
7. 題材ごとの結果と改善案をIssue #17に報告する。現時点では空の評価を成功扱いにしない。
